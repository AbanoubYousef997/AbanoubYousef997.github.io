# Abanoub Yousef — Engineering Portfolio

A responsive, static engineering portfolio for GitHub Pages, built with HTML, CSS and JavaScript. No build tools required.

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your actual GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and this README into the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Once deployed, visit `https://YOUR_USERNAME.github.io/`.

Alternatively, use any repository name, e.g. `engineering-portfolio`, and visit `https://YOUR_USERNAME.github.io/engineering-portfolio/` after enabling Pages.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your real email address.
- Replace the placeholder LinkedIn and GitHub links with your profile URLs.
- Add your actual project photos, videos, and reports. Current project visuals are original CSS illustrations, **not** project photographs.
- Add a PDF resume link only when your resume is ready for public distribution.
- Check that you have permission to publish any university or employer project materials, PLC files, network settings, or photos.

## Structure
- `index.html` — content
- `styles.css` — responsive design
- `script.js` — dynamic copyright year
